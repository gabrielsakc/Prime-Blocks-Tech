# Reciclaje de neumáticos fuera de uso (NFU / ELT) y caucho

## 1. Datos de alimentación `[LIT]`

| Concepto | Neumático de turismo (PCT) | Neumático de camión (TBR) |
|---|---|---|
| Masa unitaria | 6.5–10 kg | 50–80 kg |
| Compuesto de caucho | ~ 65–70 % | ~ 65–75 % |
| Acero (talón + cinturón) | 12–16 % | 20–27 % |
| Textil | 3–7 % | 0–2 % |
| Densidad aparente suelta de neumáticos enteros | 100–150 kg/m³ | ~ 200 kg/m³ |
| LHV | ~ 28–32 MJ/kg (neumático) | similar |

La composición del caucho incluye caucho natural/sintético, negro de humo, ZnO (~1–2 % del neumático),
azufre, aceites. El Zn y el S son relevantes para las rutas térmicas.

## 2. Proceso mecánico (a temperatura ambiente)

Recepción → (opcional) extracción del talón/destalonadora para TBR → trituradora primaria (de doble eje,
chips de 50–150 mm) → trituradora secundaria/raspadora (chips/TDF 20–50 mm, liberación del acero) →
granulador (1–20 mm) → imán(es) (el objetivo de acero ~ 99 % libre de caucho es difícil: el acero limpio
requiere varias etapas) → separación textil (aspiración neumática, mesas vibrantes) →
molinos cracker / molienda fina (polvo de 0–2 mm) → cribado → ensacado.

La molienda criogénica (LN2, caucho por debajo de Tg ≈ −60 °C) produce partículas más limpias y lisas, pero con
un consumo elevado de LN2 (típicamente 0.5–1.0 kg de LN2 por kg de caucho `[LIT]`) — justificar por la prima
del producto.

Energía `[LIT]`: trituración a TDF 20–40 kWh/t; a granulado de 1–4 mm 150–300 kWh/t en total;
polvo fino < 0.5 mm 300–500+ kWh/t.

## 3. Productos y especificaciones

| Producto | Tamaño | Especificaciones clave |
|---|---|---|
| TDF (combustible derivado de neumáticos) | 25–75 mm | contenido de alambre según el horno, ASTM D6700 (verificar) |
| Árido derivado de neumáticos (obra civil) | 50–300 mm | ASTM D6270 (verificar) |
| Granulado de caucho (crumb rubber) | 0.8–4 mm | acero libre < 0.1 %, fibra < 0.5 %, humedad < 1 % `[LIT]` |
| Polvo de caucho | < 0.8 mm | PSD (tamizado), para betún-caucho / asfalto modificado con caucho, productos moldeados |
| Alambre de acero | – | contenido de caucho (determina el precio) |
| Fibra textil | – | normalmente de bajo valor/eliminación o combustible |

Usos: betún-caucho (vía húmeda) / asfalto modificado con caucho por vía seca, productos moldeados
(esteras, baldosas, adoquines), relleno deportivo (comprobar las restricciones normativas de la UE/EE. UU. sobre el relleno de
microplásticos — `Applicability must be confirmed for project jurisdiction`), superficies de áreas de juego infantil.

## 4. Desvulcanización y procesos termoquímicos
- Desvulcanización (termomecánica, microondas, CO2 supercrítico, química): de Demo a
  comercial incipiente para reutilización parcial (mezcla del 5–20 %). Verificar referencias de proveedores.
- Pirólisis: productos aceite de pirólisis de neumáticos (~40–45 %), negro de humo recuperado rCB (~30–35 %),
  acero (~10–15 %), gas (~10–15 %) `[LIT]`. La calidad del rCB y la venta del aceite son los riesgos
  comerciales. Requiere análisis de riesgos (gas inflamable, H2S, entrada de oxígeno) y control de emisiones.

## 5. Riesgos específicos
Incendio en pilas de neumáticos (muy difícil de extinguir, humo tóxico): limitar el tamaño de las pilas y las distancias
de separación según el código local contra incendios (anexo de NFPA 1 / código local — verificar). El polvo de caucho es
combustible. Cortes con el alambre de acero; trituradoras de alto par — LOTO.

OEM candidatos (verificar): Eldan, Genox, SSI Shredding, CM Shredders, Untha, ECO Green
Equipment, integradores tipo Tyrecycle, Granutech-Saturn.
